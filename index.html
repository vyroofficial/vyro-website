It behaves like a simple set-top box: open the app, the last (or first) channel plays automatically, and CH+/CH- or the D-pad changes channels. **This app does not, and will not:** receive satellite RF directly, decrypt or bypass DRM/conditional access, scrape or redistribute broadcaster content, or ship any pirated channel list. Adding legal live channels Free TV ships with **no working channels** — only clearly-fake placeholder entries so the UI has something to show before you configure a real source. Go to **Sources** and use one of: - **Import M3U** — pick a local `.m3u` / `.m3u8` file (e.g. one you've saved from a legitimate provider) using the system file picker. - **Remote Playlist** — paste the URL of an M3U playlist you are authorized to use; the app fetches and parses it directly. - **Network Tuner** — if you own a compatible DVB-S/S2 receiver/tuner box that exposes its authorized output as a network stream URL (this is hardware- and vendor-specific — Free TV does not include or emulate any tuner driver), add that URL as a channel here. - **Local Channels** — the built-in Room database; edit `ChannelRepository .seedSampleChannelsIfEmpty()` if you want to ship your own default list inside the app instead of importing at runtime. Imported playlists replace only the channels from that same source on re-import (tagged internally by `source`), so re-importing an updated M3U won't duplicate entries or wipe your manually-added tuner channels. --- ## 6. Auto-start & Kiosk mode - **Start Live TV Automatically** (Settings) controls whether opening the app skips straight to playback — this is an in-app setting only. - True device-level auto-launch-on-boot requires either (a) the user setting Free TV as their TV box's default/home launcher via Android TV system settings, or (b) a device-owner/kiosk provisioning profile set up by whoever manages the box (common on dedicated TV-box deployments). Configure it through Android's own launcher/kiosk provisioning tools instead. - **Kiosk Mode** in-app just hides navigation chrome and keeps the app on the Live TV screen; press **Back** to exit it (documented, no hidden exit). --- ## 8.
